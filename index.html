🏢 Official GCP PCA Case Studies

Case study questions represent 20–30% of the exam score. Below is the architectural breakdown and key design patterns for each official scenario.

🏢 Cymbal Retail

E-Commerce & GenAI Modernization

Scenario: Traditional brick-and-mortar retailer scaling its online presence, handling massive holiday transaction surges, and introducing an AI shopping assistant.

  • Database Strategy: Cloud Spanner for global transactional consistency across regions; AlloyDB for high-throughput Postgres HTAP analytics.
  • Generative AI: Vertex AI Vector Search + Gemini with RAG grounded on catalog data using Cosine vector distance metrics.
  • Compute: Cloud Run for stateless containerized web frontends; Cloud Run Jobs for batch order processing.
  • Security & API: Global External Application Load Balancer with Cloud Armor WAF and Apigee API Gateway.

🏥 EHR Healthcare

HIPAA & High Availability Migration

Scenario: Healthcare SaaS provider migrating legacy colocation databases to GCP with strict HIPAA regulatory compliance and disaster recovery requirements.

  • Hybrid Connectivity: 10 Gbps Dedicated Interconnect with IPsec encryption.
  • Security & Privacy: Sensitive Data Protection (DLP API) to redact PHI/PII; CMEK/CSEK via Cloud KMS/HSM.
  • IAM: GKE Workload Identity & Cross-Cloud Workload Identity Federation.
  • Compliance Retention: Cloud Storage Bucket Lock (WORM policy) for 7-year audit logs.

🎥 Altostrat Media

Streaming Media & Petabyte Storage

Scenario: Global media platform processing raw video uploads, extracting metadata via AI, and managing multi-petabyte storage costs.

  • Storage Lifecycle & Replication: Cloud Storage Lifecycle Rules + Dual-Region Turbo Replication for 15-min RPO.
  • Stream Processing: Pub/Sub → Cloud Dataflow → BigQuery with BI Engine acceleration.
  • Analytics: BigQuery with Date Partitioning and Clustering on video tags.
  • File Storage: Cloud Filestore Enterprise for NFS POSIX video rendering workloads.

🚗 KnightMotives Automotive

Connected Vehicles & Low-Latency IoT

Scenario: Connected vehicle telemetry system collecting sensor data worldwide with near-zero RPO and RTO < 1 min disaster recovery.

  • IoT Telemetry: Pub/Sub into Cloud Bigtable formatted with `[VEHICLE_ID]#[REVERSE_TIMESTAMP]` row keys.
  • High Availability: Active-Active cross-region GKE clusters with Cloud Spanner multi-region.
  • Edge Computing: Anthos / GKE Enterprise at regional manufacturing facilities.
  • AI Defect Detection & Drift: Vertex AI Custom Training on GPUs + Vertex AI Model Monitoring for data drift detection.
